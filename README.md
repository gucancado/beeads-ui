# beeads-ui

Design system do ecossistema beeads. Publica `@beeads/tokens`, `@beeads/fonts`, `@beeads/ui`, `@beeads/charts` em npm público.

Identidade: **honey** (#FFAE00), **ink** (#0a0a0a), **paper** (#fafaf7). Tipografia: **Fraunces** (display) + **Geist Mono** (corpo).

## Uso em apps

```bash
pnpm add @beeads/tokens @beeads/fonts @beeads/ui
```

Ver `docs/PRINCIPLES.md` para princípios de design (será criado em fase futura).

## Desenvolvimento

```bash
pnpm install
pnpm storybook  # docs viva em http://localhost:6006
pnpm build
pnpm test
```
